🔑 Facebook Token Generator

⚠️ Current token mein pages_show_list permission nahi hai.
Naya token generate karein.

Step 1: Generate New Token

Neeche diye gaye link pe click karein aur permissions approve karein:

Get New Token

Step 2: Get Page Access Token

Redirect hone ke baad:

  1. Graph API Explorer khulega
  2. Query box mein likhein: /me/accounts
  3. Submit click karein
  4. Response mein se access_token copy karein

Step 3: Update .env

Copy kiya hua token .env file mein paste karein:

FACEBOOK_PAGE_ACCESS_TOKEN=YOUR_NEW_TOKEN

Step 4: Test

Command prompt mein:

python test_facebook_connection.py

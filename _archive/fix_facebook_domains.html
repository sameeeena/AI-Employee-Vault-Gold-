🔧 Facebook App Domain Fix

⚠️ Error: The domain of this URL isn't included in the app's domains.

📋 Solution - 2 Methods

Method 1: Add App Domains (Recommended)

Step 1: Open Facebook App Dashboard

Open App Dashboard

Step 2: Find "App Domains" field

Step 3: Add these domains (comma-separated):

localhost, facebook.com, developers.facebook.com

Step 4: Click "Save Changes"

Step 5: Wait 5 minutes for changes to apply

Method 2: Add Valid OAuth Redirect URIs

Step 1: Go to Facebook Login Settings

Open Login Settings

Step 2: Add Valid OAuth Redirect URIs:

https://developers.facebook.com/tools/explorer https://localhost http://localhost:8000

Step 3: Save Changes

Method 3: Direct Token Link (Quick Fix)

Agar settings mein problem ho, toh direct link use karein:

Get Token Direct

Steps:

  1. Upar diye gaye link pe click karein
  2. Facebook login karein
  3. Permissions approve karein
  4. Redirect hoga Graph API Explorer pe
  5. Query box mein likhein: /me/accounts
  6. Submit click karein
  7. Response mein se access_token copy karein

✅ After Fixing

Test karein:

python test_facebook_connection.py

Phir token generate karein:

python get_facebook_token.py
